# 实验数据整理与检查

## 核心规则

1. 先确认列含义、单位、测量顺序和哪些观测属于同条件重复。共同[信息入口](../../../references/information-intake.md)适用于独立调用本 Skill 的任务；已有信息不重复询问。
2. 原始观测只读。单位转换、分组或排除另存结果，保留行号、原值、转换关系和依据。
3. 相同读数不等于重复录入，离群点不等于错误。先标记、查记录，再决定处理；有重要歧义时展示处理对结论的影响。
4. 均值、样本标准差和均值标准不确定度有不同含义。本 Skill 提供描述统计，不把 s 直接标成 u(mean)。
5. 所有数值检查实际执行 Python；记录无效单元格和统计采用的样本，不静默过滤后称为完整数据。
6. **保留记录精度。** 数显稳定时完整保留显示值（如 `2.00`）；末位跳动时保存实际读数或变化范围和读数约定。刻度仪按实验规定及实际可辨程度估读，记下最小分度和估读位。原表无依据时不从小数位反推仪器规格。

## 工作流程

0. **信息入口**：明确本次分析目标、列/单位、仪器记录与重复条件。缺少语义时先完成能确定的结构检查，其余标明待确认。
1. **读取与核对**：检查表头、行数、缺失/非数值/非有限值、完全重复行、量程和分辨力背景。区分类别列与数值列，不把文字标签直接判坏数据。
2. **整理与统计**：用表名、量名/符号、单位和测量序号组织表格，保持自变量与响应值逐行配对。按同条件分组，执行单位换算，保留源文本、对应行和精确换算后的数值，计算样本量、均值、样本标准差和范围。A 类均值不确定度按需求交不确定度 Skill 评定。
3. **质量诊断**：检查疑似异常和随测量顺序的趋势。MAD 标记与序号斜率只是提示；不以序号冒充实际时间，不据此推断未知物理原因。
4. **处理与交接**：记录已确认修正和未解决问题。需要拟合交给拟合 Skill，需要评定测量不确定度交给不确定度 Skill；数据无法支持结论时向 Agent 返回缺口。

固定画像入口（从项目根目录运行，使用已安装依赖的 Python）：

```text
python .agents/skills/experimental-data-processing/scripts/profile.py data/demo-pendulum/raw.csv --out results/example/profile.json
```

脚本只实现数值画像，不自动读取所有仪器/单位背景或完成通用清洗；其他处理需实际运行并保存代码与依据。

## 输出规范

- `profile.json` 或等价摘要：列/单位背景、样本统计、原始行号、缺失与疑似问题、统计适用限制。
- 如做转换，另交派生数据和处理记录，不覆盖原始文件。
- 如需作图，画实测点，标图名、轴变量、单位、刻度及变换。叠加拟合曲线时与实测点区分；有依据才画误差条，标明它代表 (u)、(U) 或哪种区间。
- 给出“可继续／可用但有限制／需澄清或补充”的有理由结论。没有验收目标时，不仅凭离散大小判断好坏。

## 禁止行为

- 不为改善拟合或缩小不确定度而删点、去重、平滑或改原始读数。
- 不把缺失的仪器指标、测量条件或单位编成事实。
- 不把稳定读数当成零不确定度，不把疑似异常直接归因于系统误差。
- 不越过拟合/最终不确定度职责，不伪造执行输出。
