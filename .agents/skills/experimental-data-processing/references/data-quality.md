# 数据准备与质量检查参考

## 读取条件

遇到混合单位、重复行、缺值、疑似异常、漂移或质量判断时读此页；原始记录和用户目标优先。需要标准版本时读[共同来源登记](../../../../references/metrology-sources.md)，需要补问时读[信息入口](../../../../references/information-intake.md)。

## 处理与证据

- 保留源文件、表头/单位、行号、实验条件及原始值。另存转换/排除记录：原值、目标单位、换算关系、处理理由、影响。
- 完全重复行不自动说明重复录入；重复读数是否独立取决于测量程序。缺失/非数值/非有限单元格需计数并列出，不静默过滤。
- 样本标准差、均值标准误与仪器分量分开；先核验同条件重复和独立性。数据画像不替代不确定度评定。
- 异常值标记是调查入口，不能为了改善拟合删点。负读数可为有效差值/修正量；检查含义后再判断。序号趋势不能证明真实时间漂移或物理原因。
- 没有目标容差时只能描述发现和限制，不能单凭离散大小判断合格。只有具体记录支持时才建议重测相应部分。
