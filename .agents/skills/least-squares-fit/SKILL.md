# 拟合与模型诊断

## 核心规则

1. 先明确模型的实验依据、变量单位、参数意义和误差结构。拟合优度不能单独证明物理关系正确。
2. 区分标准不确定度、扩展不确定度与相对权重；已知绝对观测方差时不默认按残差再次缩放。
3. 不忽略重要 ux、观测相关性或参数关系。固定但有不确定度的校准量不能被遗忘，拟合均值与新观测预测要区分。
4. 选后端后按参考核对接口与版本，实际运行，检查收敛、残差、可辨识性和约束边界；不能仅看 success 或相关系数。
5. 参数、协方差顺序和依赖关系一起交付；不将受约束参数当成新的独立输入。

## 工作流程

0. **信息入口**：按共同[入口规则](../../../references/information-intake.md)检查目标、数据列/单位、模型和观测不确定度。缺权重来源时先评定来源，或明确采用未加权模型。
1. **确定统计任务**：确认拟合/校准/预测目标，模型、初值、固定参数与约束的依据。先核对每对 `x,y` 的原始行与单位，查看散点和量程。若线性化，检查定义域并在变换后的尺度上评定权重及误差，交代拟合采用的尺度。
2. **选后端**：按下表选择，再读[后端与输入说明](references/backends.md)。

   | 条件 | 后端 |
   | --- | --- |
   | 常规线性/非线性，y 标准差或完整 y 观测协方差 | SciPy curve_fit |
   | 命名参数、固定参数或参数间代数关系 | lmfit |
   | 非零 ux，x/y 两侧测量误差都需计入 | odrpack |

   `backend=auto` 先检查 ux，再检查表达式/固定参数，其余用 SciPy。边界在三个后端均可给出。双侧误差与参数关系并存时先将关系代入模型；当前适配器不直接支持这两项的任意组合。
3. **执行求解**：调用固定入口，保留输入、输出和环境。依赖或方法不适用时如实返回，不偷偷换成不同统计问题。
4. **诊断与回查**：检查残差随自变量和观测顺序的变化、自由度、参数秩/条件数、触边和协方差。普通含截距直线在独立同方差且由残差估计散布时，用 `s_r = sqrt(SSE/(n-2))` 及 `n-2` 自由度计算参数标准不确定度，保留斜率和截距的协方差。若报告相关系数，用原精度计算；课上给定阈值时注明判据和条件，模型还需物理依据与残差支持。
5. **交接**：把参数、完整协方差、约束关系和局限交给 Agent；传播到最终测量结果由不确定度 Skill 完成。

```text
python .agents/skills/least-squares-fit/scripts/fit.py examples/fit-nonlinear.json --out results/example/fit.json
```

## 输出规范

`fit.json` 含模型/参数定义、自由参数顺序、协方差、标准不确定度、预测/残差、自由度、权重约定、后端版本、求解状态和警告。固定/受约束参数关系单列；协方差不可用时明确标空，不能捏造精度。

参数、权重、残差、协方差在机器结果及后续传播中保留计算精度。正文中的参数与各自的标准不确定度按[修约规则](../measurement-uncertainty/SKILL.md#最终修约与末位对齐)成对展示。用于校准或推算其他物理量时，交接参数及完整协方差，再由不确定度 Skill 传播。

结果解释说明物理和统计适用条件。局部非线性近似不可靠、触边或不可辨识时，说明是否需要 profile/有依据的重采样等进一步分析；当前脚本不自动完成这些方法。图表按任务需要实际生成。

## 禁止行为

- 不静默忽略 ux、相关观测、参数约束或固定量的不确定度。
- 不将 U、允差或错误的单位直接当作观测标准差。
- 不为了更漂亮的参数而删点、强制过原点、换模型或任意缩放协方差。
- 不把局部参数置信区间当成最终被测量覆盖区间，不伪造求解/图表证据。
