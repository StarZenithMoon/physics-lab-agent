# 测量不确定度分析

## 核心规则

1. **先定义被测量与条件。** 写清 Y=f(X)、物理依据、单位、修正和重要忽略项。测量结果是估计，不自动是真值。
2. **区分误差与不确定度。** A/B 类表示评定方法，不等同于随机/系统效应；仅给定标准不确定度却未说明其评定来源时，记“已给标准不确定度，A/B 未指定”，不自行归为 B 类。重复性小不能消除偏差或模型缺项。
3. **先转为标准不确定度，再合成。** 区分分辨力、允差、证书 U/k、样本标准差与均值不确定度；保留来源、分布和自由度，不重复计入仪器效应。
4. **显式处理依赖关系。** 检查共享校准、环境、拟合参数协方差和相关重复观测，不能无依据默认独立。
5. **方法须满足条件。** 一阶近似、正态/t 近似、MC 输入分布和覆盖因子都有依据；双路一致不证明模型正确。
6. **执行规格与报告模型同源。** 从题目声明的输入清单、模型和单位直接生成机器可读的传播规格，逐项核对名称、数值、单位、分布与相关性，并检查每个已声明输入在规格中恰好出现一次。不手工抄写子集，不把省略输入或换用简化模型的试算规格当作主结果；正文模型与运行规格由同一来源生成。
7. **交叉核对必须同题同量。** 解析/精确解与 MC 只在同一模型、同一输入集合、同一输出量之间比较。差异超出按样本量算得的抽样精度时，视为待排查的不一致：先查输入遗漏、单位与尺度、模型和分位定义，再重算或重跑；不得择一报出，不得用分布形状、量级相近或辅助核验通过来掩盖矛盾。
8. **抽样精度必须实际计算。** 报告端点、均值或标准不确定度的精度前，计算对应标准误或判稳统计量；批次极差是描述性量，不自动等于标准误。判稳对象须覆盖均值、标准不确定度和两个区间端点，不能只判其一。
9. **所有数值实际运行。** 默认项目 Python；使用 MATLAB 时也须有真实代码与输出。包括转换、传播、覆盖、比较和修约，不用心算或未执行代码代替证据。主结果、辅助核验与展示数值应来自同一份已保存产物。先落地最小完整结果再补充诊断；自适应采样要设停止规则和次数上限。
10. **保留保护位数，最终再修约。** 正文交付执行下方「最终修约与末位对齐」；机器结果与后续传播保留未修约值。保护位数与最终展示只能各有一套约定，并明确标注当前数值属于哪一种。
11. **重要缺项按事实处理。** 使用共同[信息入口](../../../references/information-intake.md)；有依据的后备假设标为暂定，决定性数据/模型无法确定时给符号或条件式结果。

## 工作流程

0. **信息入口**：整理已给、可推导、可检索、实验特定缺项和可选背景；只询问影响目标的重要缺项，记录事实与假设。
1. **确定任务和测量模型**：区分直接/间接测量、输入分量、覆盖、结果比较或预算设计；明确被测量、条件、修正符号及重要来源。把输入清单落成机器可读规格，检查输入集合、顺序、单位和分布与题设一致，再开始计算。
2. **评定 A 类**：依据观测对象和独立性计算单次/均值/先验重复性的不确定度与自由度。拟合参数及协方差接收拟合 Skill 的真实结果，不在这里重新拟合。
3. **评定 B 类**：读取仪器规格/证书，按有依据的分布换算；检查量程、分辨力、修正、环境和来源重叠。证书只给 U 与 k 时仅得到标准不确定度；覆盖概率或分布须由证书/规范声明，未声明时不写成 95% 正态。
4. **传播与预算**：计算灵敏度和完整协方差贡献，检查模型局部性；给出预算及主要来源。分量相关时保留协方差项符号。用独立手算或另一实现复核一阶方差与灵敏度；对和式或有界输入，另算输出支持范围并与实际样本范围对照，检查是否把分量半宽或方差尺度写错。
5. **选择或对照 MC**：输入分布与联合结构明确后运行；记录样本、种子、批次、定义域、停止规则和稳定性，并确认运行规格覆盖全部已声明输入。无效样本的处理须写明，不静默删除。对照任务按要求跑两路；差异需按规则 7 解释，不强制凑一致。
6. **覆盖与比较**：按目标概率、分布/自由度确定适用因子或 MC 区间；若输出正态分布及其标准差已由题设完全确定，可直接使用对应正态分位数，不因未给样本自由度而拒绝该分支，此时端点标准误也须用该输出的尺度计算。需要时按含相关项的差值不确定度比较测量结果。不能统一设 k=2 或临界值 2。端点比较使用相同的尾概率定义。
7. **报告前验证**：核对来源换算、单位、自由度、预算总和、相关项、覆盖含义和数值证据；按下方「分位数端点的抽样精度」复算端点精度；用「结果一致性核对」逐项检查正文、修约产物与机器结果。错误回到对应步骤。工具报错先判断属于输入契约、脚本实现还是环境问题，保留原始报错，按职责说明或转交，不改写证据绕过。
8. **交付与建议**：说明结果类型、主要来源、信息状态和局限；有目标时评价是否满足要求，提出有依据的最小补救或改进建议。时间或步数受限时先交付结果、不确定度、区间与修约，再补诊断；不因追加采样而迟迟不落盘。

按需读[科学方法说明](references/uncertainty-guide.md)中的对应部分：A 类、B 类、传播、自由度/覆盖、比较、任务分支和报前核验。领域能力不限于现有命令的参数范围；遇到工具未覆盖的方法，实际执行适当 Python/MATLAB 计算并附证据，或如实说明不能完成。

## 常用输入量的操作规则

| 已知信息 | 评定动作 |
| --- | --- |
| 同条件独立重复 n 次，估计均值 | 样本标准差 s 用 n−1 作分母；取 u=s/√n，自由度 n−1。仅一次且无适用先验重复性时不能从单值估计 A 类分量；按需求补测或注明可评定的 B 类分量。 |
| 同条件预实验 n 次得到适用的 s，本次独立重复 m 次 | 取 u=s/√m，自由度沿用预实验的 n−1；m=1 时取 u=s。 |
| 校准证书给扩展值 U 和 k | 同单位下取 u=U/k；另记证书给出的修正及其符号。仅凭 U 与 k 只得到标准不确定度；覆盖概率或分布须由证书或规范声明，未声明时不得推断为特定分布或 95% 覆盖。已知正态双侧覆盖概率 p 且只给半宽时，按 p 对应的正态分位数换算。 |
| 仪器给分辨力 d、区间或允差 | 确认量程、指标公式和分布依据。舍入到最近显示档且均匀时用 d/√12；半宽 a 的矩形/三角模型分别用 a/√3、a/√6。模拟表若按满量程百分比标级，计算基准用满量程。 |

将同一零点、标定或修正量作为共享输入建模，或用有依据的协方差传播。仅在分量独立且近似适用时用 Welch–Satterthwaite 与 t 分布评定覆盖；查整数 t 表按题目约定向下取整，使用连续自由度时写明方法。MC 区间按任务规定报告端点和区间类型。

## 分位数端点的抽样精度

需要判断 MC 端点是否稳定、或判断两路端点差异是否有意义时，实际计算端点标准误，而不是凭观感给定小数位：

    SE(q_p) = sqrt(p(1−p)/n) / f_Y(q_p)

- p 是该分位对应的尾概率：双侧 95% 等尾区间的下端点取 0.025、上端点取 0.975。不把覆盖概率、1−覆盖率或单侧概率代入。
- f_Y 是被测量输出分布在 q_p 处的密度，用与传播一致的分布计算：解析密度、数值卷积或数值微分 CDF；只有输出确为正态 N(μ,σ) 时才用 φ(z_p)/σ。不得把标准正态密度直接用于尺度不同的输出，也不得用输入分量密度或正态近似替代非正态输出密度。
- 量纲与尺度要闭合：SE 必须与输出同单位。正态输出时密度分母含 σ，漏掉或多乘一个尺度因子都会使结论系统性偏移。
- n 与所报分位数使用的样本一致：合并样本用合并后的 n，单批用该批 n；不得用每轮采样数或批次极差冒充。
- 稳定性分别给出均值、u、下端点、上端点的判据和实测值；两端的跨度各算各的，不混用上下端点极差。批次极差只作描述，直接与标准误或区间半宽比较后才可下结论。
- 任何“远小于抽样波动”“显著不符”“一致”等判断，先列出所用 SE 或等价精度数值；没有该数值时只作描述性比较。

## 最终修约与末位对齐

1. **只在最终展示时一次修约。** 本项目的默认报告格式采用 ties-to-even（五凑偶）；只有当报告格式没有指定其他规则时才使用。第一舍弃位为 5 且其后全零或无数字时，保留末位为奇数则进一、为偶数则舍去；5 后还有非零数字则按通常进位处理。例如保留一位小数，`2.4500 → 2.4`、`2.5500 → 2.6`、`2.4501 → 2.5`。
2. **先选不确定度有效位数，再对齐。** 通常取两位。若有明确的原结果末位，且它与不确定度首位同位，或原末位更高、只需合理补零即可对齐，项目默认格式可取一位。先核对尾零是否在转录中丢失；相差多个数量级时回查单位、模型、分辨力及遗漏来源。计算结果的浮点打印位数不代表原结果末位。进位后按最终不确定度的末位修约估计值，保留所需尾零。例如原报 `12.3 mm`、`u=0.042 mm`，采用一位规则时展示 `(12.30 ± 0.04) mm`。任务另有位数或修约约定时优先执行并记录依据。
3. **常数和函数量。** 精确常数可按计算需要取足够位数，实测或校准常数按来源精度及不确定度建模。函数量先用未修约输入和传播律算出不确定度再定末位。题目若要求估位，固定其余输入，变动所查输入原末位一个单位，计算函数值变化的绝对值；其最高非零位给出影响的数位估计。最终位数仍以传播后的不确定度为依据。
4. **全篇只保留一套展示精度。** 正文、结果小节和修约展示中的同一数值必须位数、单位、符号完全一致；正文可以保留未修约值，但须明确标注“保护位数/未修约”，且不得与修约展示并列成两种说法。
5. **配对对象必须正确。** 修约工具的 `value` 是该量的估计值，`u` 是同一量本次要展示的标准或扩展不确定度，两者含义不同。只报告某一分量的标准不确定度、且没有与之配对的独立估计值时，写 `u=…` 即可，不要把它同时当作 value 和 u 拼成 `u ± u`。区间端点若不是对称分布的中心量，单独报告端点和区间类型，不与中心估计强行配对。
6. **运行修约并核对输出。** 将最终要报的估计值与正不确定度批量交给下方工具，用返回字符串填正文，注明单位和 `u` 或 `U`。非对称覆盖区间单独报告端点、类型和概率，展示位数应有精度依据。机器报告填同一份计算产物的未修约数值。

```text
python .agents/skills/measurement-uncertainty/scripts/round_report.py results/rounding-input.json --out results/rounding.json
```

输入按标签组织，例如 `{"mean":{"value":12.3,"u":0.042,"recorded_value":"12.3"}}`。通常只给 `value,u`；有同一量、同单位的真实原结果文本才给 `recorded_value`。题目指定有效位数时给 `digits`；规定其他修约方式时实际运行对应计算。工具字段 `u` 接受本次要展示的标准或扩展不确定度数值，物理含义由报告注明。输出是字符串，仅用于展示。

## 输出规范

按用户目标给适用内容，完整分析包括：

1. 被测量、模型、测量条件、修正、假设和依据。
2. 预算表：输入/来源、单位、A/B 方法、分布、标准不确定度、灵敏度、自由度和相关性；不得强行把相关项写成全正百分比。预算须覆盖题目声明的全部输入，方差贡献之和与总方差可核对（有相关项时单列协方差），并指出主导来源。
3. 实际代码/命令、环境和运行输出；长计算可链接完整文件。正文数值、修约产物与机器结果可逐项追溯到同一份已保存产物。
4. 估计值、标准不确定度；若报告 U 或区间，写明因子/概率、自由度或 MC 区间类型及依据。区间端点若附精度，须说明是端点标准误、判稳结果还是展示修约位，并给出样本量和所用尾概率。
5. 核验结果、重要信息缺口、暂定假设、主要贡献和适度建议。没有验收目标不能仅凭不确定度大小说“合格”。
6. 一致性核对结论：列出实际执行的核对项和通过情况，不一致处说明如何修正。

### 结果一致性核对（交付前逐项通过）

- 正文、修约展示与机器报告中的同一数值完全一致（位数、单位、符号、正负号）；保护位数只有一种展示约定。
- 标准不确定度、扩展不确定度和分布区间分别标注，不把 u 与 U 或分位端点混排，也不给 u 自身再配一个同值的不确定度。
- 预算的输入集合等于题目声明集合；方差份额、总方差和主导项可由产物重算。
- 解析与 MC 的差异已与算得的抽样精度比较，结论引用具体数值；两路针对同一模型和同一输出量。
- 辅助核验（简化模型、部分输入、换后端的试算、只覆盖子集的解析解）单独标注，不进入主结果字段，也不作为主结果通过的证据。
- 每个“合格/受限/需重测”判断都写明判据，且判据对象与被判对象一致；校验值只与其所属文件比较，派生文件不沿用源文件校验值，缺失单位或命名差异只作范围说明，不直接降级数值结果。
- 时间受限时已落盘的最小结果仍包含估计值、u、区间（如需要）和一致的修约展示。

描述 MC 与解析结果的差异时，报告真实差值与抽样稳定性依据；“远小于抽样波动”“显著不符”等定量强弱判断需有实际计算的抽样误差尺度支持。没有评估时只作描述性比较，不能由批次极差直接推断总体标准差估计或区间端点的精度，也不能用未经推导的固定小数位替代端点标准误。

项目文件格式见[契约](../../../docs/CONTRACTS.md)，完整报告可用[模板](../../../templates/report.md)。部分分析不强制生成无关文件；固定评测任务遵守该题产物约定。

## 禁止行为

- 不编造观测、仪器指标、模型、分布/协方差、自由度、引用或运行输出。
- 不把 A/B 类当作随机/系统误差，不把 s 当 u(mean)，不重复计入同一仪器效应。
- 不忽略修正和相关性，不把允差/扩展不确定度直接合成，不固定所有覆盖因子。
- 不把线性近似当作精确结果，不用统一 5% 强制判所有两路比较，不静默删无效 MC 样本。
- 不声称符合未经核实的标准，不用双路一致、量纲正确或区间重叠证明模型/真值正确。
- 不为缩小不确定度删除数据，不把不确定度大或检验有差异直接判成必须重测。
- 不让执行规格漏项或换模型后仍把结果归给原被测量；不以简化试算、部分输入或辅助核验的输出填写主结果字段。
- 不把覆盖概率当尾概率，不把标准正态密度用于尺度不同的输出，不用批次极差或观察到的端点重复性冒充端点标准误，不在缺乏精度数值时宣布端点一致或稳定。
- 不在正文与修约展示中并列同一数值的两套精度，不把单一分量的 u 自身配成 `±` 对，不用展示位数的说法与实际位数不符。
- 不用错配的校验对象或不适用的判据给结果贴“合格/受限”，不为赶进度而省略已声明输入的传播或跳过最小结果交付。
