## 1. 测量模型与修正

定义 Y=f(X1,…,XN)，说明被测量的条件、变量、单位及物理依据，纳入重要的校准/参考标准、环境、几何、方法和操作者效应。修正 C 作用于示值 I 时，例如 Y=I+C，明确符号和来源；修正估计为零不代表其不确定度为零。

估计值按未修约输入计算。灵敏度为零/近零时先检查高阶影响，不能据此自动删去该来源。量纲正确只是一项检查。

## 2. A 类评定

- 同条件独立重复观测 q1…qn：均值 qbar，样本标准差 s（ddof=1）；均值标准不确定度 u(qbar)=s/sqrt(n)，自由度 n−1。s 描述单次读数离散，不等于均值不确定度。
- 存在漂移、相关或条件变化时，先判断同一均值模型是否成立，不机械除 sqrt(n)。
- 单次观测且没有适用的先验重复性，不能由该一个读数估计重复性；可用非统计信息作为 B 类来源，说明限制。
- 若已验证的先验/预实验标准差 s 适用，单次后续读数可用 u=s；m 次独立读数均值可用 u=s/sqrt(m)。自由度来自先验 s 的估计，不自动改为 m−1。
- 拟合参数与协方差由拟合 Skill 评定并交接。传播时保留其约束与相关性；不能只接收参数标准差后默认独立。

## 3. B 类评定与仪器来源

每项记录来源、单位、分布、原始界限/覆盖信息、转换方法和标准不确定度。A/B 是评定方法，不是随机/系统误差的两类标签。

用户给定一个标准不确定度，不代表它由B类方法得到。评定过程未提供时，保留其已知标准不确定度身份并注明A/B未指定，不猜测历史来源。

| 来源与假设 | 标准不确定度 |
| --- | --- |
| 证书给 U 与适用的覆盖因子 k | u=U/k |
| 正态/t 模型下给区间半宽 a 与覆盖信息 | 按对应分布因子换算，不当作矩形界限 |
| 对称矩形分布半宽 a | u=a/sqrt(3) |
| 区间 [a−,a+] 内均匀 | 中点为估计值，u=(a+−a−)/sqrt(12) |
| 对称三角分布半宽 a | u=a/sqrt(6) |
| 对称梯形：底宽 2a、顶宽 2aβ | u=a*sqrt((1+β²)/6)，0≤β≤1 |
| 数字步进 d，最近档舍入且矩形假设适用 | u=d/sqrt(12) |

准确度等级若按满量程定义，就按满量程计算限差；数字仪器按厂家实际公式和所用量程。模拟读数不统一采用“半分度”规则。证书覆盖、分辨力、重复性和厂家技术指标若有重叠，避免重复相加。已知修正要施加，修正的不确定度仍传播；共享校准要考虑相关。

显示稳定不能说明不确定度为零。没有分布信息时说明歧义，采用有依据并标记的假设；不默认所有允差都是正态或矩形。不能为合成而把各来源人为变成共同概率等级。

## 4. 一阶传播与相关输入

在输入估计值处求灵敏度 ci=∂f/∂xi。局部线性近似合理时：

`uc²(y) = Σ ci² ui² + 2 Σ(i<j) ci*cj*cov(Xi,Xj) = cᵀ Σ c`。

协方差项保留灵敏度符号。共享标准、共同环境、拟合结果或重复使用同一修正量都可能产生相关，必要时按独立来源分解。

常用独立输入特例也有适用条件：和/差用方差相加；乘积/比值及幂函数的相对传播仅在一阶近似成立、相关性可忽略及分母有意义时使用。角度求导/传播需用弧度。相关时使用完整矩阵，不能直接套独立输入公式。

## 5. 自由度、覆盖与扩展不确定度

独立重复均值常为 n−1；n 个观测、m 个独立拟合参数的残差自由度通常 n−m。B 类自由度充分大可近似无限，但不能一概如此。

对独立且近似条件合理的输出贡献 ui(y)=ci*ui，Welch–Satterthwaite 近似为：

`νeff = uc⁴ / Σ[ui(y)⁴/νi]`。

相关性或明显非正态占主导时，不能无条件套用。需要双侧覆盖概率 p 时，适用条件下选 `kp=t.ppf((1+p)/2,νeff)`，再 `Up=kp*uc`；有依据的正态极限用相应正态因子。上述因子必须在 Python/MATLAB 中实际计算。

k≈2 与约95%只是近似正态、自由度较大等条件下的近似。先合成标准不确定度，再扩展，不先给每项乘因子后当标准量相加。用于选择覆盖因子的 t 近似，不等于每个 A 类输入在 MC 中都必须按 t 抽样。

输出分布及其标准差若已完全给定为正态，可直接用 `norm.ppf((1+p)/2)` 求覆盖因子；不需要另有样本自由度。标准差由有限数据估计、其可靠性影响覆盖时，才按适用条件处理自由度/t近似或其他分布传播。不把“脚本未自动算k”写成“数学上无法给k”。

当前固定脚本不自动求 νeff/k。需要该分支时另运行合适计算并保存依据；不能因工具字段缺失就统一 k=2 或丢掉自由度。

## 6. 蒙特卡洛与方法比较

若估算覆盖端点的抽样精度，在样本独立、分位点密度正且平滑的条件下，可用分位数渐近标准误 `sqrt(q*(1-q)/M)/f(Q_q)`；q是该端点的累计概率（如0.025），不是区间覆盖概率0.95。说明该近似的条件或使用有依据的重采样/次序统计方法。标准误按M的平方根衰减，降到原来的1/r通常需r²倍样本；固定样本数或批次极差不能认证任意小数位。0.1修约步距是一位小数，0.01是两位，不混称。引用标准条款须核验，不能把经验样本数建议写成通用充分条件。

给定输入概率分布及联合结构后抽样，代入共同测量模型，统计输出估计、标准不确定度与指定类型的覆盖区间。记录种子、样本数、批次、有限性/定义域检查和稳定性；不静默删掉无效样本改变输入分布。

强非线性、边界或输出明显不对称时，一阶近似可能失效。报告点值 f(x)、MC 均值等所代表的量，不擅自换成中位数并隐去差别。等尾区间与最短区间不同；当前脚本只给等尾区间。

对照两路时必须使用一致的模型、来源和相关结构。差异可能来自近似、分布、实现或抽样；没有统一相差5%就通过的标准。MC 批次标准差稳定不表示覆盖端点已精确到报告位数。两路一致也不能排除同一个模型缺项。

后端、支持的联合分布和当前限制分别见 methods.md、tool-selection.md。工具未覆盖的概率模型不偷偷替换成正态/独立。

## 7. 测量结果一致性比较

先确认相同被测量和兼容条件。差值 D=A−B 的标准不确定度为：

`u²(D)=u²(A)+u²(B)−2cov(A,B)`。

独立时协方差为零。适用时计算 `tobs=(A−B)/u(D)`，根据差值的自由度、覆盖水平和单双侧约定选临界值；不要统一用2。参考值只有确实精确时才能令其不确定度为零，否则计入来源。

相容不证明相等或模型正确；有差异不单独证明系统误差原因。仅看区间是否重叠不能替代所需检验。

## 8. 特定任务、预算与实验改进

- **直接测量**：给估计值、重复性和适用 B 类来源，避免重复计入同一效应。
- **间接测量**：明确模型，传播所有重要输入、常数/修正及拟合参数相关项。
- **拟合/校准**：参数估计归拟合 Skill；本 Skill 处理这些结果到目标量的传播，区分拟合均值与新观测预测。
- **预算**：列输入、来源/类型、分布、u、ci、自由度、相关项和输出贡献。排序主要来源时注意协方差可能为负，不强行全正归一。
- **实验改进**：根据目标和主导来源考虑增加独立重复、改量程/仪器、校准或方法；重复增加不能消除共享偏差。未给依据不把总预算平均分配到各输入。

## 9. 报告前核验与质量结论

核对观测统计、来源转换、修正符号、单位、灵敏度、方差总和、协方差和重复计入；核对自由度、覆盖含义、实际代码输出、保护位数和最终末位对齐。使用 ± 时标明它表示什么。

结合数据检查与拟合诊断，给有依据的结论：适合分析／可用但有限制／需要澄清或补充／目前无法定量确定。只有有具体证据（如过载、确认的程序失效）时才判需要重测，并限定涉及哪些读数/运行。

没有目标/容差时不能判断是否满足要求；不因不确定度大、孤立异常或检验差异就要求整套实验重做。提出依据支持的最小补救方案，区分假设与事实。
