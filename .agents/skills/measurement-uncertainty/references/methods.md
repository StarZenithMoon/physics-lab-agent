# 初稿计算能力与方法边界

以 [JCGM 100](https://www.bipm.org/en/doi/10.59161/JCGM100-2008E) 和 [JCGM 101](https://www.bipm.org/en/doi/10.59161/jcgm101-2008) 为方法参考，版本与后续补充见 [官方目录](https://www.bipm.org/en/committees/jc/jcgm/publications)。本脚本不是完整的 GUM 合规认证工具。

1. `assess.py` 支持独立重复测量均值 s/sqrt(n)、数字分辨力 d/sqrt(12)、矩形允差半宽 a/sqrt(3)、证书 U/k 及已给标准不确定度。它只转换单个来源，不自动判断来源重叠或物理修正。
2. `propagate.py` 使用模型注册表中的公式与显式梯度，一阶方差为 c^T*Sigma*c。相关预算分别列对角贡献和成对协方差项，不丢失符号。
3. MC 支持独立正态/矩形输入及标准差参数化的 t 分布（df>2），相关输入只支持联合正态。t 的 scale 不是标准差，脚本会进行换算；df<=2 时无有限方差，不接受 u 参数化。
4. 模型和所有输入采用契约列出的 SI 单位；未知模型不自动 eval 字符串。比值和物理模型存在定义域；任一批次出现无效样本就报错，不能通过删样本改变分布。
5. MC 拆成固定独立批次并比较各批次标准差。`stable` 使用显式配置的批次相对极差阈值，仅表示该统计量的工程诊断，不证明覆盖区间端点已达 GUM 所需精度。正式报告需针对所报位数增加自适应样本量/端点稳定性验证。
6. 公式与 MC 的相对差只报告数值和提示，不直接转换为 accepted。端点比较和适用性判断由任务判据规定。
7. 不自动计算有效自由度或覆盖因子。仅当调用者明确给出有依据的 k 时，附上 k*u 的扩展不确定度；MC 区间按指定覆盖概率输出等尾分位数。禁止把两者未经说明混为同一种区间。
8. 当前 MC 后端为 numpy-scipy（默认）或 punpy（显式选择）。两者使用相同的独立 Generator 批次样本；后者经 Punpy 传播，仍由适配器拒绝无效样本并统一统计。原库的 ddof 约定可能不同，保留 native u 并标明本报告 std_ddof=1，不能把这一有限样本差异当作物理冲突。

模型分布和相关性是模型输入，并非脚本从原始数据自动发现的事实。拟合协方差应由拟合结果传入；只有正态近似有依据时才采用联合正态传播。模型卡中的简化条件必须逐实验核对。
