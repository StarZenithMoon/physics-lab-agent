# 共同信息入口

供 Agent 和三个 Skill 共同使用。已有信息只登记一次，各 Skill 补查自身任务所需的缺口。

## 先分类，再决定动作

| 信息类别 | 处理 |
| --- | --- |
| 用户/实验资料已给 | 保留原值、单位和来源，不重复询问 |
| 可由数据或模型推导 | 实际执行计算，保留依据 |
| 可可靠检索的通用事实 | 查标准机构、原始文献、仪器厂家等可靠来源，并核对版本/条件 |
| 只有本次实验掌握的事实 | 合并询问重要缺项，不用网上通用信息替代 |
| 可选背景 | 仅在相对于目标影响可忽略且有依据时省略 |

重要信息包括：被测量、测量方程、数据列/单位、读数次数和重复条件、仪器型号与量程、分辨力/技术指标、有效校准及修正、环境、采样、输入相关性、所需不确定度/覆盖概率及适用的报告规范。

## 查什么、问什么

- 可查：精确常数、标准换算、公开参考数据、已知型号的手册和技术指标、标准的版本/条文。只查当前模型需要的内容，核对单位、条件和覆盖信息。
- 需实验事实支持：实际仪器及所用量程、实际校准证书、装置和程序、样品、环境、已施加的修正、读数是否同时/独立。资料中查不到时问用户。
- 优先来源：BIPM/JCGM、NIST/CODATA、标准官方平台、厂家资料、原始文献与可靠教材。记录出处、版本/访问日期和适用条件。

## 缺项与后备方案

只问会影响结果的重要缺项，尽量一次合并；可从资料推导/检索的内容先自行解决。不反复追问已回答的信息。

用户无法补充时，不无限等待。仅在资料或实验背景支持时采用最窄的后备假设，说明依据，将结果标为暂定/limited；多个合理假设会显著改变结果时给主要条件方案或敏感性比较。用户明确要求不假设时只给能确定的内容。

原始观测、关键单位/尺度、被测量或测量关系完全无法确定时，不能编造数值来补齐。给符号/条件式结果和所需信息，必要时返回 needs_information。数据“模拟”与“真实”必须明确，不把假设写成已经发生的实验事实。
