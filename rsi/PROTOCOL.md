# 三 Skill 优化实验约定

本约定说明项目内的Skill候选评测流程。候选数量、权重和阈值是项目定义的开发设置。比较批次内科学量表和运行预算保持不变。

## 可变范围

三组件为 measurement-uncertainty、least-squares-fit、experimental-data-processing。每候选保存三份完整SKILL.md，只允许一份相对**当前接受版本**改变。可改description、判断规则、路由、工作流和输出说明；名称、科学责任、禁止行为、章节结构、可选支持资源链接及按需使用条件保留。结构检查不证明语义，需独立维护审核。

其他Skill、全部references、脚本、数值库、Agent、模板、题目、容差、量表、模型和资源冻结。工具bug或评分问题另开修复/实验，不靠Skill补偿错误工具，也不在候选间换口径。项目实际使用的Skill不会自动安装或覆盖。

## 角色与数据

1. 新提议上下文只读导出train包、当前Skill和train执行产物；不读selection/test明细，不将案例ID或参考值写成特例。记录实际提议模型/会话、包/回答摘要与训练假说。
2. 维护者审核候选职责、科学边界和支持资源；审核绑定父版本、候选和变更来源摘要。
3. 任务Agent在新工作区用候选做题，不改Skill、工具、原数据或judge。
4. 固定evaluator核对数值/证据，任务会话之外的操作者逐项科学复核，给理由、证据和产物/轨迹摘要。空白/过期复核禁止选版；AI辅助复核不等同正式同行评审或双人盲评。
5. selection仅用于选版。设计者看过部分材料，不能称完全未知；当前落实的是导出包和新提议上下文不含selection细节，不冒充OS或容器隔离。

## 预算与选择

每候选train10题×3、selection8题×3，共54次初始新会话。仅API/进程故障每题额外最多一次，最坏108次；科学错误、预算耗尽、越界新产物和缺报告按原规则失败，不重跑挑答案。固定输入篡改、保存/清理/宿主余量等基础设施错误先诊断，不混作模型分。

服务商明确返回 credits/余额或长期配额耗尽时，保存当题记录、完成清理后停止整个批次，不触发普通 API 重试或下一题。受此影响的 split 不提供有效正式总分，已完成 split 可独立核验。补测须等待服务恢复，保留原始失败、冻结信息及补测依据，不覆盖旧记录。

同一实验内保持冻结的模型、Python/依赖、OpenCode版本/transport、步骤预算、300秒、1GiB整树提交内存、CPU10%与准入/运行余量；75%通知仅预警。历史v0为24步，v2.2维护批次为60步，比较时列明差异。串行、逐题原子保存并验证整树退出，不关闭用户应用。

optimization.json预注册候选数与顺序，默认不确定度、拟合、数据处理三个候选；拒绝也消耗名额。根据当前最优及历史候选的train反馈继续，不导出selection分数/失败明细到提议包。

选版采用noise-aware退步规则，除判定规则外，题库、评分、模型、预算、重复次数和训练/选版数据保持不变：

1. selection三遍均分必须高于上一版，任何正增益均可晋级；不得以显示精度造成的微小正差代替真实变化。
2. 单题均分下降超过3分、严格通过次数减少至少2/3，或关键门槛通过次数减少至少2/3，记为实质退步。
3. 全部selection严格通过次数、证据完整率或格式合规率不得比上一版少超过1个观测；24个观测时即允许至多1/24的波动。
4. 一次重复波动不阻断版本；同一任务三遍中至少两遍从通过变为失败则阻断。
5. 固定输入被改写、越界输出、报告保存失败、进程未回收或其它完整性故障继续直接阻断晋级。

该规则控制有实际影响的退步，并允许三次重复中的有限波动。每轮记录六维分、成功率、证据率、预算失败、逐案差值、遍间标准差、耗时与provider token/cost。三遍只描述波动，不宣称显著提升；同题差值不等于随机流配对。provider费用0不等于已核验免费。

## 版本与恢复

保存三Skill bundle、父子关系、提议来源、审核、diff、train/selection及所有原始尝试。**先完成仓库外无remote的Git归档，再更新最优与轮次。** 拒绝也归档，不删除失败。

完整split可继续；partial split不自动重复付费任务，先查task_event、task_state、run_manifest与清理状态。Git归档已完整但提交失败，可校验全部摘要后恢复提交，不重跑模型、不覆盖原档。初始化失败保留现场再恢复记录，不宣称任意时点无损续跑。

## 基线与最终验收

旧v0原样保留，新框架新冻结。继承旧测量必须用原source.zip的evaluator重放原档，核对原始/有效视图/复核摘要、18个任务可见工作区、54次提示、运行与评分依赖、模型/环境/预算。证书明确“继承测量、0次新基线调用”，不重标原报告。搬迁后的缺report.json错误路径仅在比较时规范化，原错误和分数不改；任何实质执行/评分变化需新基线。没有旧档可以实际运行新的三Skill v0后初始化。

候选预算结束、版本选定后才使用test split检查最终版本，不将测试反馈用于本轮提议。不默认开启外部遥测服务。
