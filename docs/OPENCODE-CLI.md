# OpenCode CLI 配置

本文说明如何在本机运行 Agent。OpenCode、模型服务和凭据由使用者自行配置；配置文件与密钥不提交到仓库。

## 配置

在仓库根目录创建 Python 环境并安装项目依赖。安装 OpenCode CLI 后，运行项目配置入口生成本机专用配置：

    python -m tools.opencode_cli configure

需要连接模型服务时，按服务商说明在本机 OpenCode 凭据库或当前进程环境中配置密钥。不要把真实密钥写入项目文件、命令历史或公开 issue。

## 检查与运行

查看当前配置：

    python -m tools.opencode_cli --help

项目运行入口会检查 CLI、Python 环境和配置。真实模型调用需要明确启用执行选项，并遵守对应的任务预算。数值模块和参考案例自检无需模型服务，参见 README 的验证安装章节。

## 配置边界

项目配置保存在被忽略的本机文件中。切换服务商或模型时记录服务商标识、模型 ID、时间和相关运行条件；不能仅凭配置名称推定上游模型版本固定不变。
