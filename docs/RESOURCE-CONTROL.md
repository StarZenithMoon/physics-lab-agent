# 运行资源限制

Agent 任务由运行器在受控进程树中执行。资源参数定义在 `rsi/config.json`，并随评测冻结记录保存，确保同一比较批次使用一致条件。

## 默认限制

| 限制 | 行为 |
| --- | --- |
| 整题进程树内存 | Windows Job Object 设置硬上限，并记录预警线 |
| CPU | 设置进程树 CPU 上限和任务进程优先级 |
| 数值库线程 | 限制为单线程，减少并发资源占用 |
| 进程数 | 超过配置上限时终止任务 |
| 并发 | 同时只运行一个受控任务 |
| 主机余量 | 启动前检查可用内存，运行中监控最低余量 |
| 墙钟时间 | 设置单题执行时限，启动等待单独记录 |
| 输出日志 | 流式写入并限制单文件大小 |

## 任务生命周期

1. 获取任务槽并检查内存准入条件。
2. 创建受控 Job Object，在资源限制生效后启动执行进程。
3. 记录运行事件、状态、资源信息和产物清单。
4. 任务结束后回收整个进程树，再保存结果和运行清单。
5. 核验清理状态后处理临时目录；保存或回收异常时停止后续批次。

资源限制只管理本任务的进程和资源，不构成文件或网络访问沙箱。Windows 模型执行依赖 Job Object；其他平台上的可用功能以运行器实际支持为准。
