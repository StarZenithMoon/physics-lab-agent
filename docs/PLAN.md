# 项目方案

## 项目目标

Physics Lab Agent 将大学物理实验数据处理组织为可检查、可执行、可复现的领域 Skill，由 Agent 根据任务需要调度数据检查、模型拟合和测量不确定度分析。

## 处理流程

1. 明确被测量、原始数据、仪器条件和报告要求。
2. 检查数据列、单位、重复条件、异常值和转换记录。
3. 选择有物理依据的测量模型，说明假设、修正和适用范围。
4. 按需拟合并传递参数、协方差和残差诊断。
5. 评定输入量及相关性，传播不确定度并检查数值稳定性。
6. 生成机器可读结果、人类可读报告和可复算证据。
7. 关键信息不足时说明缺项，不据此编造数值。

## v3 公开评测

v3 随附的公开评测集共 24 题：train 10 题、selection 8 题、test 6 题。train 用于候选改进反馈，selection 用于版本选择，test 用于候选冻结后的检查。本文及 README 中的评测分数只描述该数据集、评分规则和对应运行条件。

量表采用六个项目定义的维度：数据 15、模型 20、结果 25、方法 20、复现 15、表达 5。任务成功、证据合规和格式合规分别报告，不能用高平均分抵消关键科学错误。具体要求见 [科学六维量表](EVALUATION-RUBRIC.md)。

## RSI 方法

每轮只修改一个 Skill，保留完整版本快照。候选从 train 反馈形成，在冻结条件下复测 train 与 selection；test 不参与候选生成和版本选择。三次重复用于描述运行波动，不作为统计显著性证明。

执行协议见 [RSI 研究说明](RSI-RESEARCH.md)、[RSI 评测约定](../rsi/PROTOCOL.md) 和 [固定评测层](../evaluation/README.md)。

## 适用范围与限制

本项目提供研究用计算流程和验证工具，不是计量认证系统。自动化可以检查数值和证据，不能单独证明测量模型适用于具体装置。需要实验事实、仪器条件或校准信息时，应根据原始记录补充。
