# 项目结构

仓库包含运行入口、领域 Skill、共享计算模块、公开案例及验证代码。全部路径相对于仓库根目录，不依赖外部工作区。

| 路径 | 内容 |
| --- | --- |
| .agents/skills/ | 数据处理、最小二乘拟合和测量不确定度 Skill |
| .opencode/agents/ | Agent 入口说明与权限配置 |
| labcore/ | 数据读取、拟合、传播、报告和交付实现 |
| evaluation/ | 公开评测题、参考值、评分和数值自检 |
| data/ | 模拟案例及归档公开数据 |
| references/ | 信息采集和计量方法来源 |
| rsi/ | 候选生成、版本快照、冻结与运行编排 |
| examples/ | 实验输入和 OpenCode 配置模板 |
| docs/ | 架构、评测、安装和可移植性说明 |
| tests/ | 数值、评测、接口与运行边界检查 |
| templates/ | 实验报告模板 |

Skill 说明方法条件、信息要求和输出规范；labcore 提供共享数值实现。评测代码与任务执行流程分开，公开参考答案用于独立核对。
